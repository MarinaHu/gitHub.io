# Yiqin Hu Medical & Scientific Writing Portfolio

A simple static portfolio site designed for GitHub Pages.

## Files

- `index.html` — site content
- `styles.css` — layout and visual design
- `script.js` — small utility script

## Before publishing

1. Replace all `href="#"` placeholders with your real links.
2. Add your writing samples. PDF files can be placed in a folder such as `samples/`.
3. Update each sample card with the audience, purpose, and your role.
4. Do not upload confidential hiring exercises, unpublished client work, or other material you do not have permission to share.

## Publish with GitHub Pages

Create a repository and upload these files to the repository root.

Then in the repository:
`Settings → Pages → Build and deployment → Source → Deploy from a branch`

Choose your publishing branch (typically `main`) and the `/ (root)` folder.

GitHub Pages will publish the site from that source.

## Suggested repository names

For a user site:
`YOUR-GITHUB-USERNAME.github.io`

For a project site:
`medical-writing-portfolio`

A user-site repository gives you the cleanest default GitHub Pages URL.
